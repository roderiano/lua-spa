# Module `runtime_assets`

Client-side JavaScript runtime for SPA execution.

---

## Overview

The `runtime_assets` module contains the JavaScript code embedded in the HTML generated by the backend. It implements the component lifecycle, rendering, state updates, event handling, and DOM hydration.

---

## Main Runtime JS Functions

- **`parseTemplate(template, context, registry)`**
  - Converts HTML into a VNode tree, interpolating expressions and resolving components.

- **`createApp(config, registry)`**
  - Creates the application, mounts the root component, and starts the lifecycle.

- **`mount`, `mountComponent`, `mountElement`**
  - Mount components and elements into the DOM.

- **`patch`, `patchElement`, `patchChildren`**
  - Update the DOM according to state/props changes.

- **`patchElementEvents`**
  - Manages event listeners and dispatches actions.

- **`bootstrap`**
  - Global function that initializes the application by reading the registry and config from HTML.

---

## Execution Flow

1. The backend injects the runtime JS into the HTML.
2. The browser executes `LuaSpaRuntime.bootstrap()`, which reads the component registry and configuration.
3. The root component is mounted and the lifecycle is started.
4. State changes automatically trigger DOM updates.

---

## Backend Integration

- The runtime expects to find `<script type="application/json" id="lua-spa-registry">` and `<script type="application/json" id="lua-spa-config">` in the HTML.
- Actions and lifecycle defined in Python are converted to JS functions by the backend.
